# Simple Interest Calculator

## Description

This project contains a simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period provided by the user.

The script is intended as a basic example of shell scripting and is part of the IBM Git and GitHub final project.

## Formula

The simple interest is calculated using the following formula:

SI = (P × R × T) / 100

Where:

- **P** = Principal amount
- **R** = Annual rate of interest
- **T** = Time (in years)

## Usage

Run the script using:

```bash
bash simple-interest.sh
```

Enter the requested values:

- Principal amount
- Rate of interest
- Time period

The script will display the calculated simple interest.
